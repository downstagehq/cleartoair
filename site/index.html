How it works

It watches the things that fail quietly on a tournament stream.

Graphics are the easy part. Grassroots broadcasts usually go wrong because a source stopped, a caster's audio dropped, or someone changed the OBS scenes after rehearsal. Clear to Air checks for those before and during the show.

Preflight

A lamp that tells you whether the show is ready.

Preflight checks the OBS connection, the eight show scenes, the overlay browser sources, the audio in every scene, that the graphics sit above the game capture, that no rehearsal source is on program, that the sample event is gone, that no simulator is feeding the graphics, the replay buffer, the recording tracks and the free disk space.

It runs every ten seconds and on demand. The lamp is green when nothing fails and nothing warns, amber when there are only warnings, and red when something fails. Every problem comes with a fix written for the operator: which tab, which button, or which OBS setting.

Drift detection

Shows you where OBS no longer matches the collection.

Somebody "just tweaked one thing" in OBS after rehearsal. Drift detection compares what OBS is running with the collection Clear to Air generates: the scenes, the sources in each scene, whether each one is visible, the browser-source URLs and the audio.

Every difference is listed by scene and source. Read the list before you reinstall the collection, because a reinstall replaces changes made by hand in OBS.

Watchdogs

A caster on camera with no audio is caught in about ten seconds.

Four watchdogs run every five seconds: a caster's camera on program while their audio is silent, a game feed that stopped sending data, the replay buffer off while a series is live, and a recording drive filling fast with little space left. Each one shows up as a preflight warning until it clears.

For the silent caster it acts by itself: it reloads that person's audio source, at most once a minute. If the voice still does not come back, it tells you to have them rejoin with the same invite link.

Graphics

Scorebug, lower thirds, ticker and full-frame cards for every game.

Each pack has four pages that OBS loads as browser sources: in-game (scorebug, ticker and lower third), full-frame cards, standby and the caster desk. Every pack has roster, bracket, scoreboard and schedule cards, all but Apex add head-to-head and MVP, plus what the game's format needs: map veto for CS2 and VALORANT, the draft for Dota 2 and LoL, standings for Apex, the set for fighting games, match stats for EA FC and game-by-game for Rocket League.

Packs are HTML and CSS under the MIT licence, as is the shared renderer they draw with, so you can restyle one, build your own, and share or sell it. Event colours, logo and font are set once in Setup and flow into every page.

Live data

Five games can feed the graphics directly. The rest get a manual desk.

Where the publisher provides a live feed, it drives the scores, clocks and player stats with no typing: CS2 and Dota 2 through Game State Integration, Rocket League through its Stats API, League of Legends through the Live Client Data API, and Apex through the LiveAPI in private matches.

Each adapter is built from the publisher's documentation and tested with simulators and sample data. None has run against a live game yet. A Record raw game data switch on each adapter saves what the game sends, so the first real matches can be checked against it.

VALORANT has no live API, so it gets a manual round desk. After a map you can paste the end-of-game scoreboard text; Clear to Air reads the player rows, shows them by team, and applies them when you confirm. Fighting games and EA FC use the manual desk too, and every game can import teams and brackets from start.gg. Each game has a simulator, so you can rehearse a full match with nobody playing.

Runs on your OBS

It does not replace OBS. It stands next to it.

Clear to Air never sits between OBS and your encoder. A small agent runs on the broadcast PC, talks to OBS over OBS's own websocket, serves the overlays as local browser sources, and runs preflight, drift detection and the watchdogs on that machine.

The control room is a web page the agent serves at 127.0.0.1:7700. Remote seats are in beta: a producer, scorer or viewer on another laptop uses the desk through a relay that the broadcast PC dials out to. They have been tested over the internet, not yet on a real show. Use ours at room.cleartoair.com, free while it is in beta, or run the relay yourself.

  • Local first. If the venue internet drops, the agent, the overlays and the show keep running. One exception: VALORANT map art loads from valorant-api.com, so it will be missing offline.
  • Nothing installed inside OBS. No plugin to break on the next OBS update. It uses obs-websocket, which ships with OBS.
  • A normal OBS scene collection. Clear to Air builds it and installs it into OBS's own collection folder. From there OBS treats it like any other collection.

Free and open source

Free to use, free to change, yours to run.

Clear to Air costs nothing. There is no licence key, no watermark and no account. Run it on your own PC for as many shows as you like, for as long as you like.

Questions

The ones organisers ask first.

Is it really free?

Yes. The app is AGPL-3.0+ and the overlay packs and their renderer are MIT. Nothing in the app is held back for paying users. The project is paid for by supporters, sponsors, and setup and custom-pack work for leagues and events.

How finished is it?

It is early. It has been tested with the built-in simulators, sample data shaped from each game's documentation, and one real OBS setup. No adapter has run against a live game yet and it has not carried a real show; the first real-game tests are planned. Remote seats have been tested over the internet, not yet on a show. Rehearse a full show with it before you put it on air.

Does it replace OBS?

No. OBS keeps doing the capture, mixing, encoding and streaming. Clear to Air builds the scenes, feeds the overlays, cuts between scenes, and watches for the problems OBS does not warn you about.

Does it work offline?

Yes. The agent runs on the broadcast PC and serves the overlays itself, so a show keeps running with no internet. VALORANT map art is fetched from valorant-api.com and will be missing offline. Remote seats go through the relay, so they need a connection to it.

Which games have live data?

CS2, Dota 2, Rocket League, League of Legends and Apex (in private matches), each through an adapter for the publisher's own feed, so far tested with simulators and sample data only. VALORANT, fighting games and EA FC are run from a manual desk, with team and bracket import from start.gg. For VALORANT you can also paste the end-of-game scoreboard text to fill in player stats.

Can I bring my own design?

Yes. Colours, logo and font are set per event, and team colours per team. The packs are HTML and CSS under the MIT licence, so a designer can restyle one or replace it, and the control room keeps driving it.

Is it allowed by the publishers?

Game State Integration is an official Valve feature for CS2 and Dota 2. Rocket League's Stats API is part of the game, and the Apex LiveAPI is Respawn's own. Riot's policy allows broadcast overlays in OBS and bans overlays that give players a real-time advantage in game; Clear to Air only makes the first kind. Clear to Air does not read game memory or inject into a game client. Its optional Rocket League fallback, SOS, needs the BakkesMod mod, which only loads with anti-cheat off.
