# Screenshot list for the user guide

Captured by `node tools/docs/shots.mjs --install <unzipped release>` (real OBS, throwaway data dir); `node tools/docs/build-site.mjs` then copies them into `site/docs/`.

Every image the guide pages reference, with the state to set up before capturing. Capture at 1600 × 900 unless the row says otherwise, and save as `docs/guide/img/<name>.webp`.

General setup for all shots unless a row says otherwise:

- Agent running on port 7700, OBS open with the WebSocket server on and the **ClearToAir** collection installed and active.
- Open a tab directly with `?tab=`, for example `http://127.0.0.1:7700/?tab=data`. Valid values: `show`, `match`, `graphics`, `data`, `rundown`, `preflight`, `setup`.
- Use only the built-in demo event's fictional names (COMMUNITY CUP; teams Alpha, Bravo, Charlie, Delta; players such as Zephyr, Kestrel, Rift, Ember; talent Riley Chen, Morgan Blake, Casey Diaz, Jordan Park) or neutral examples.
- No real IP addresses, tokens, invite codes for a live room, or passwords visible. Where a token or link is on screen, use a throwaway agent data dir (`--data-dir`) so nothing real leaks.
